# Repository workflow

- Read `CONTRIBUTING.md` before creating a branch or changing repository files.
- Follow its `main`-based PR workflow and `<type>/<description>` branch naming rules, including for automated work. Use `feature/`, `fix/`, `chore/`, or another documented type according to the task purpose.
- Preserve existing changes when switching or renaming branches, and run the checks required for the change scope.
